# Package starter

A template for new PHP packages: Pest, PHPStan, Pint and Rector, wired into composer scripts and CI.

### Using the template

1. Rename `rooberthh/php-package-starter` and the `Rooberthh\PackageStarter` namespace in `composer.json`, `tests/` and `src/`.
2. Replace `tests/Unit/ExampleTest.php` with real tests.

### Scripts

- `composer test`: run the Pest suite.
- `composer lint`: run Rector, Pint and PHPStan, in that order.
- `composer rector:check`: show Rector's changes without applying them.
